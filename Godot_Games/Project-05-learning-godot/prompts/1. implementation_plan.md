# Implementation Plan: Mini-Game Hub & Samurai Endless Runner

This plan outlines the creation of a **Mini-Game Hub** (a game selection menu) in Godot 4, along with the first playable mini-game: a side-scrolling, left-to-right **Samurai Endless Runner**. We will integrate the user-provided Samurai pixel art sprites and Brackeys slime sprites for obstacles.

## Proposed Changes

We will organize the project cleanly inside the workspace. The main menu will serve as the gateway, and each learning mini-game will live in its own subdirectory (e.g., `res://runner_game/`).

#### [NEW] [player.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/player.tscn) and [player.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/player.gd)
* **Description**: The player character controller using `CharacterBody2D`.
* **Visuals**: `AnimatedSprite2D` utilizing:
  * `Assets/FREE_Samurai 2D Pixel Art v1.2/Sprites/RUN.png` (96x96 per frame, 16 frames) for running.
  * `Assets/FREE_Samurai 2D Pixel Art v1.2/Sprites/IDLE.png` (96x96 per frame, 10 frames) for jumping/falling frames or starting.
* **Mechanics**:
  * Gravity, jumping (with inputs `ui_accept` or `space`), and landing detection.
  * Collision shape tailored to the samurai sprite.

#### [NEW] [obstacle.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/obstacle.tscn) and [obstacle.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/obstacle.gd)
* **Description**: Obstacles that move leftwards to be dodged by the samurai.
* **Visuals**: Green or purple slimes from `Assets/brackeys_platformer_assets/sprites/slime_green.png` or `slime_purple.png` (using standard sprite configuration).
* **Mechanics**:
  * Movement speed matching the runner's speed.
  * An `Area2D` collision triggers game over upon hitting the player.
  * Automatic queue-free once they exit the screen.

#### [NEW] [pause_menu.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/pause_menu.tscn) and [pause_menu.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/pause_menu.gd)
* **Description**: Overlay UI that appears when pausing.
* **Buttons**:

  * **Restart**: Reloads the current scene.
  * **Menu**: Returns back to the Mini-Game Selection Hub.

#### [NEW] [game_over_menu.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/game_over_menu.tscn) and [game_over_menu.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/runner_game/game_over_menu.gd)

## Verification Plan

### Manual Verification
1. Run the project in Godot using `godot` runner.
2. Confirm the Main Menu renders nicely and clicking "Samurai Runner" opens the game.
3. Verify that pressing `space`/`up` triggers a jump.
4. Verify that obstacles spawn and move left, and that jumping over them increases the score.
5. Verify that colliding with an obstacle triggers the Game Over menu with the correct score.
6. Verify that pressing `ESC` opens the Pause menu.
7. Verify that navigation buttons ("Back to Hub", "Resume", "Restart") work flawlessly.
