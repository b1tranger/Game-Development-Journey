# 3D Chicken Walking Simulator

We want to build a simple yet extremely premium and interactive 3D Chicken Walking Simulator game using the provided asset: [clay_chicken_maruf.dae](file:///c:/Users/gsmur/Documents/Godot/game-01/Assets/clay_chicken_maruf.dae). The game will be built inside the Godot 4 project framework and integrated as the second playable game in the portfolio mini-game selector hub.

Since the clay chicken model itself does not contain skeletal animations, we will craft **procedural animations** (wobbling, waddling, jumping stretch-and-squash, and cluck expressions) driven programmatically by GDScript to give the chicken a charming, physics-based "claymation" personality.

---

## User Review Required

We are designing this game to feel extremely premium, warm, and alive. Here are the core design decisions we plan to implement:

> [!IMPORTANT]
> **Procedural Animations for Rigless DAE Model**
> Since the clay chicken model contains no skeletal mesh animations, we will implement custom procedural math (sine wave oscillations on rotation and height) in the player's controller script.
> * **Idle State**: Subtle, slow vertical scaling (breathing effect).
> * **Moving State**: Up-and-down hop + left-and-right waddle (rotation around forward axis) synced to movement speed.
> * **Jump State**: Squash upon landing, vertical stretch during ascent.
> * **Cluck Action**: Pressing Left-Click/Enter will make the chicken tilt its head back, squish/stretch along the vertical axis, and play a cluck sound effect.

> [!TIP]
> **Visual Style & Cozy Lighting System**
> To create a high-end visual aesthetic:
> * We will set up a custom **WorldEnvironment** with warm sunset/sunrise lighting, volumetric fog, high-quality Screen Space Ambient Occlusion (SSAO), and glow.
> * The pasture ground will be styled with a clean stylized grid/soft gradient material (harmonious green-yellow palette) rather than a plain color.
> * We will add elegant floating dust/firefly particles (`GPUParticles3D` or `CPUParticles3D` depending on compatibility) to make the space feel magic and alive.

### Chicken Walking Simulator (New Component)

#### [NEW] [chicken_game.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_game/chicken_game.tscn)
* The main 3D world scene containing:
  * **WorldEnvironment**: Ambient lighting, procedural warm sky, volumetric fog, glow, SSAO.
  * **DirectionalLight3D**: Beautiful soft sun casting shadows.
  * **Static Ground**: Green pasture styled with a nice material.
  * **Boundaries & Obstacles**: Stylized trees (Cylinder and Sphere collisions) and rocks (Sphere colliders) lining the perimeter to keep the chicken safe inside.
  * **Player Node**: Instanced `chicken_player.tscn`.
  * **Collectibles**: Instances of gold corn seeds that spawn randomly in the pasture.
  * **HUD CanvasLayer**: Glassmorphic UI featuring a glowing title, "Corn Eaten" counters, control reminders, and an interactive cluck button.
  * **Background Music**: Loaded from existing audio streams.

#### [NEW] [chicken_game.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_game/chicken_game.gd)
* Manages game state (corn gathered score).
* Spawns new corn collectibles randomly when one is eaten.
* Listens for Pause input (`ui_cancel` / ESC) and instantiates the 3D game pause menu.

#### [NEW] [chicken_player.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_player.tscn)
* The 3D CharacterBody3D scene containing:
  * **CollisionShape3D**: Vertical Capsule collider.
  * **Pivot (Node3D)**: Model container to allow offset rotations and squash-and-stretch scales.
    * **clay_chicken_maruf.dae**: Loaded and instanced inside the Pivot.
  * **SpringArm3D**: Spring-arm centered on the player to prevent camera collision.
    * **Camera3D**: High-end perspective camera.

#### [NEW] [chicken_player.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_player.gd)
* Controls third-person WASD/Arrow keys movement relative to camera look angle.
* Mouse orbit controls for camera rotation (horizontal and vertical clamp).
* Physics integration (gravity, jump velocity, friction, and smooth movement vectors).
* **Procedural Animation Engine**:
  * Oscillates chicken's Y-position and Z-rotation during movement using `sin(time * speed)`.
  * Triggers vertical squash-and-stretch scaling vectors on Jump, Land, and Cluck triggers.
  * Handles SFX player connections for jump, steps, and clucks.

#### [NEW] [corn_collectible.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_game/corn_collectible.tscn)
* Area3D scene containing a gold sphere mesh (or small box cluster representing corn), an OmniLight3D for a magical golden glow, and a simple floating/spinning animation script.

#### [NEW] [corn_collectible.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_game/corn_collectible.gd)
* Detects when the player overlaps the collectible.
* Triggers an elegant floating "+1 Corn" text pop-up.
* Signals the main game script to increase the score, play a crunch/chewing SFX, and respawn.

#### [NEW] [chicken_pause_menu.tscn](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_game/chicken_pause_menu.tscn)
#### [NEW] [chicken_pause_menu.gd](file:///c:/Users/gsmur/Documents/Godot/game-01/chicken_game/chicken_pause_menu.gd)

## Verification Plan

### Automated Tests
* We will verify the syntax of all GDScript files by running the Godot compiler lint check command if available.

### Manual Verification
1. **Selection Menu**: Click "2. Chicken Simulator" from the main selection menu, verifying it transitions perfectly into the 3D scene.
2. **Camera Controls**: Move the mouse to rotate the camera around the chicken, checking for smooth orbiting and correct boundary clamping.
3. **Movement & Physics**: Move using WASD, checking that the chicken moves relative to the camera face. Jump with Space to check gravity and boundary colliders (rocks, fences).
4. **Procedural Animations**: Verify the chicken bounces up/down and rolls side-to-side while walking, breathes slightly while idle, and squashes/stretches on jumps or clicks.
5. **Gameplay & HUD**: Eat gold corn collectibles, ensuring they disappear, trigger a sound/floating label, add to the HUD score, and cause a new corn to spawn.
6. **Pause Menu**: Press ESC/Cancel, verify the game pauses, and click Resume, Restart, or Exit to select menu to verify they work flawlessly.
