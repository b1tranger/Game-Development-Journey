# Walkthrough: Godot Platformer Puzzle Template

## What Was Built

A complete Godot 4.4 platformer puzzle game template inspired by "That Level Again", with **28 files** across 3 directories:

### Project Structure
```
project-04/
├── project.godot              # Config: 800×480, input map, autoload
├── icon.svg                   # Simple SVG icon
├── EXPLANATION.md             # ~17KB tutorial document
├── scripts/
│   └── game_manager.gd       # Autoload singleton (level progression)
├── components/                # 5 reusable game objects (10 files)
│   ├── player (.tscn/.gd)    # CharacterBody2D with movement/jump
│   ├── door (.tscn/.gd)      # Lockable Area2D exit
│   ├── spike (.tscn/.gd)     # Hazard that respawns player
│   ├── key_item (.tscn/.gd)  # Collectible that unlocks door
│   └── hidden_button (.tscn/.gd) # Nearly invisible wall switch
└── scenes/                    # 7 scenes (14 files)
    ├── main_menu (.tscn/.gd)  # Title screen with Play/Quit
    ├── win_screen (.tscn/.gd) # Victory screen with Play Again/Menu
    └── levels/
        ├── level_1 — Walk to door
        ├── level_2 — Jump over spike
        ├── level_3 — Find key to unlock door
        ├── level_4 — Find hidden wall switch
        └── level_5 — Stand still for 3 seconds
```

### Game Flow
Main Menu → Level 1–5 → Win Screen → (Play Again / Main Menu)
