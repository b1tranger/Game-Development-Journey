# Godot Platformer Puzzle Game Template

A template project for learning Godot 4.4, inspired by "That Level Again" — a platformer puzzle game where levels look the same but require different solutions. The game includes a main menu, 5 puzzle levels, and a win screen.

## Game Concept

- **Genre**: 2D Platformer Puzzle
- **Reference**: "That Level Again" — each level has the same visual layout (platforms, a player, and a door) but the hint text changes, requiring a unique solution each time.
- **Flow**: Main Menu → Level 1 → Level 2 → ... → Level 5 → Win Screen → (Restart / Main Menu)

### Level Solutions (5 levels)
1. **"Just reach the door"** — Walk right to the door
2. **"Jump over the obstacle"** — Jump over a spike to reach the door  
3. **"The door is locked. Find the key"** — Collect a key item to unlock the door
4. **"Think outside the box"** — Door is unreachable normally; player must press a hidden button on the wall
5. **"Sometimes doing nothing is the answer"** — Player must stand still for 3 seconds, then the door opens

#### [NEW] [game_manager.gd](file:///e:/Git_WIP/2.%20Personal%20Repositories/Game-Development-Journey/Godot_Games/project-04/scripts/game_manager.gd)

### Level Components (Door, Spike, Key, Button)

#### [NEW] Door (door.tscn + door.gd)
- `Area2D` with collision shape and `ColorRect` visual
- Property: `locked` (bool) — if locked, player needs a key
- When player enters and door is unlocked → emits `level_completed` signal

#### [NEW] Spike (spike.tscn + spike.gd)
- `Area2D` that kills/respawns the player on contact

#### [NEW] Key Item (key_item.tscn + key_item.gd)
- `Area2D` collectible that disappears on pickup
- Emits signal to unlock the door

#### [NEW] Hidden Button (hidden_button.tscn + hidden_button.gd)
- `Area2D` nearly invisible button on a wall
- When player touches it → unlocks/opens the door

### Levels

#### [NEW] Level Base (level_base.tscn + level_base.gd)
- Common layout: floor, walls, ceiling (using `StaticBody2D` + `CollisionShape2D`)
- Hint `Label` at the top showing puzzle instructions
- Player spawn position
- Door position
- Background color via `ColorRect`

#### [NEW] Levels 1–5
Each level inherits the base layout and adds its own twist:

| Level | Hint Text | Mechanic |
|-------|-----------|----------|
| 1 | "Just reach the door" | Walk right to the door |
| 2 | "Jump over the obstacle" | Spike in the path, jump over it |
| 3 | "The door is locked. Find the key" | Key hidden on a platform, collect to unlock door |
| 4 | "Look for a hidden switch" | Hidden button on wall opens the door |
| 5 | "Sometimes doing nothing is the answer" | Stand still for 3 seconds to open door |
